# Payment flow manual test checklist

- [ ] Новий користувач: Step2 → "Далі" → відкривається сторінка оплати.
- [ ] Після успішної оплати повертає на сайт та автоматично відкривається Step3 без заходу на Step1.
- [ ] Оновлення сторінки на Step3 не скидає замовлення (resume за token/order).
- [ ] В іншому браузері/інкогніто з `?svb_token=<token>` (або `?svb_order=<token>&order_id=<id>`) відкривається Step3, якщо оплата підтверджена.
- [ ] Якщо не оплатив і повернувся → бачить Step2 з кнопкою оплати.
- [ ] Повторні кліки по "Далі" не створюють багато інвойсів/замовлень.
